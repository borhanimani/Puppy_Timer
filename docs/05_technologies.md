# Technologies

## Overview

Puppy Timer was developed using **Python** and several libraries and technologies and also using **AI** tool for the graphical user interface, voice processing, audio input, and application development.
The main technologies used in the project are listed below.

## Core Technologies

- Python
- PySide6
- Vosk
- sounddevice
- NumPy
- Bootstrap Icons

## Development Concepts

In addition to the libraries above, the project uses several programming concepts and techniques, including:
- Object-oriented programming
- Modular design
- Separation of concerns
- Multithreading
- Queue-based audio processing
- Algorithm design
